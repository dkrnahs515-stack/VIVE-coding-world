# 🎮 VIVE Coding World

강서청소년회관 **바이브 코딩 1·2 참가자들이 직접 제작한 웹 기반 미니게임 아케이드**입니다.

HTML, CSS, JavaScript로 제작된 게임을 한곳에서 선택해 플레이할 수 있으며, GitHub Pages를 통해 별도의 설치 없이 PC·태블릿·스마트폰 브라우저에서 실행할 수 있습니다.

메인 화면의 **AI 바이브 코딩 참가자 활동 기록**에서는 참가자들이 4회기 동안 게임을 기획하고, AI로 제작하고, 오류를 해결하고, 완성작과 느낀 점을 공유한 과정을 `기억의 조각` 형태로 살펴볼 수 있습니다.

## ✍️ 기억의 조각 내용 입력 방법

참가자 회고는 `games/memory_fragments/participants.js` 한 파일에서 입력합니다.

1. 파일 안의 빈 참가자 객체를 참가자 수만큼 복사합니다.
2. `nickname`에는 실제 이름 대신 참가자가 동의한 닉네임을 입력합니다.
3. `idea`, `joy`, `challenge`, `solution`, `learning`, `message`에 참가자 답변을 입력합니다.
4. 원하는 경우 `schoolLevel`, `gameTitle`, `gameUrl`, `emoji`, `color`를 추가합니다.
5. 정확한 나이, 성별, 학교명, 반, 연락처, 계정명은 입력하지 않습니다.

`nickname`이 빈 객체는 공개 화면에서 자동으로 제외됩니다. 일부 회고 항목이 비어 있으면 해당 답변만 표시하지 않으며, 참가자 내용이 하나도 없어도 네 구역 탐험과 엔딩은 정상적으로 실행됩니다.

## 🎮 이용 방법

1. [메인 아케이드](https://dkrnahs515-stack.github.io/VIVE-coding-world/)에 접속합니다.
2. 플레이할 게임 카드를 선택합니다.
3. 게임 화면의 규칙과 조작 방법을 확인합니다.
4. **PLAY NOW** 버튼을 눌러 게임을 시작합니다.
5. 게임이 끝나면 다시 플레이하거나 메인 아케이드로 돌아갑니다.

## ➕ 새로운 게임 추가 방법

1. `games/` 폴더 안에 새 게임 폴더를 만듭니다.
2. 게임의 시작 파일 이름을 `index.html`로 지정합니다.
3. 루트 `index.html`의 `.game-container` 안에 새 게임 카드를 추가합니다.
4. 카드의 링크를 `games/새게임폴더/index.html`로 연결합니다.
5. GitHub Pages 배포 후 PC와 모바일에서 실행 상태를 확인합니다.

> 게임 폴더만 추가하면 메인 카드가 자동으로 생성되지 않습니다. 반드시 루트 `index.html`에도 게임 카드를 추가해야 합니다.
