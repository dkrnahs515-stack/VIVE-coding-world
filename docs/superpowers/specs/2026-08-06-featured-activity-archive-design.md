# AI 바이브 코딩 활동 기록 대표 영역 설계

## 목적

VIVE Coding World 홈페이지에서 `기억의 조각`을 일반 게임 중 하나가 아니라 가장 중요한 대표 콘텐츠로 보여준다. 방문자는 첫 화면에서 AI 바이브 코딩 참가자들이 4회기 동안 어떤 과정을 거쳐 게임을 만들었는지 이해하고, 활동 기록 탐험으로 바로 이동할 수 있어야 한다.

## 정보 우선순위

홈페이지의 콘텐츠 순서는 다음과 같이 변경한다.

1. VIVE Coding World 브랜드 헤더
2. AI 바이브 코딩 참가자 활동 기록 대표 영역
3. 참가자 제작 미니게임 목록
4. 제작 안내 푸터

현재 게임 목록 마지막에 있는 `MEMORY FRAGMENTS` 일반 카드는 삭제한다. 대표 영역 자체가 `games/memory_fragments/index.html`로 연결되므로 같은 링크를 중복 노출하지 않는다.

## 대표 영역 문구

- 상단 배지: `2026 AI VIBE CODING · ACTIVITY ARCHIVE`
- 제목: `AI 바이브 코딩 참가자들의 활동 기록 살펴보기`
- 설명: `참가자들이 AI와 함께 아이디어를 기획하고, 게임을 제작하고, 오류를 해결하며, 완성작과 느낀 점을 나눈 4회기의 과정을 살펴보세요.`
- 주요 버튼: `AI 바이브 코딩 활동 기록 살펴보기`
- 보조 표시: `4 SESSIONS`, `PARTICIPANT STORIES`

## 4회기 활동 과정

대표 영역 안에서 다음 네 단계를 짧은 카드 또는 칩으로 보여준다.

1. `1회기 · 아이디어와 게임 기획`
2. `2회기 · AI를 활용한 제작`
3. `3회기 · 오류 수정과 문제 해결`
4. `4회기 · 완성작 공유와 활동 성찰`

이 문구는 방문자가 참가자 개인 회고를 열어보기 전에도 전체 활동 흐름을 이해하게 하는 요약이다. 실제 참가자별 활동 기록과 느낀 점은 기억의 조각 게임 안에서 닉네임 기반 카드로 확인한다.

## 시각 디자인

대표 영역은 기존 네온 아케이드 디자인을 유지하면서 일반 카드보다 높은 위계를 갖는다.

- 홈페이지 콘텐츠 폭 전체를 사용하는 대형 패널
- 청록·보라·분홍 네온 그라데이션 테두리와 은은한 발광 효과
- 기억 조각을 상징하는 별빛, 작은 사각 파편, 연결선 장식
- 왼쪽에는 제목·설명·활동 단계·버튼
- 오른쪽에는 `4 SESSIONS`와 `PARTICIPANT STORIES`를 강조하는 기록 오브젝트
- 강한 움직임은 사용하지 않고 파편 부유와 빛 이동 정도의 장식 애니메이션만 적용
- `prefers-reduced-motion` 환경에서는 장식 애니메이션을 제거

## 미니게임 영역

대표 영역 아래에 다음 제목과 설명을 추가한다.

- 제목: `참가자 제작 미니게임`
- 설명: `AI 바이브 코딩 활동에서 완성한 다양한 웹게임을 직접 플레이해 보세요.`

기존 12개 게임 카드는 현재 링크와 순서를 유지한다. VIBE ESCAPE는 기존처럼 외부 사이트로 새 창에서 연결한다.

## 기억의 조각 시작 화면 보강

`games/memory_fragments/index.html`의 시작 화면은 게임 제목을 유지하되 활동 기록의 목적을 더 명확히 설명한다.

- 활동 기록 성격을 나타내는 문구 `AI VIBE CODING · ACTIVITY ARCHIVE` 추가
- `AI 바이브 코딩 참가자들의 활동 기록 살펴보기` 문구를 제목 또는 제목 바로 아래의 강조 문장으로 노출
- 설명에 기획, AI 활용 제작, 오류 해결, 완성작 공유의 4회기 흐름 포함
- 기존 네 구역 탐험, 개인정보 안내, 시작 버튼 기능은 그대로 유지

## 반응형 및 접근성

- 데스크톱에서는 대표 영역을 2열로 배치한다.
- 태블릿과 모바일에서는 기록 오브젝트를 제목 아래로 이동하고 활동 단계 카드를 1열 또는 2열로 배치한다.
- 모바일 첫 화면에서 제목과 대표 버튼이 먼저 보이도록 장식 크기를 줄인다.
- 대표 영역 전체를 링크로 만들지 않고 명확한 `<a>` 버튼을 사용한다.
- 제목 구조는 홈페이지 제목 다음에 대표 영역 `<h2>`, 미니게임 목록 `<h2>` 순서로 구성한다.
- 텍스트 대비와 키보드 포커스 표시를 유지한다.

## 기술 변경 범위

- 수정: `index.html`
- 수정: `games/memory_fragments/index.html`
- 수정: `games/memory_fragments/style.css`
- 수정: `README.md`
- 수정 또는 추가: 대표 영역과 링크 순서를 검증하는 테스트

별도 프레임워크, 이미지 파일, 서버 저장 기능은 추가하지 않는다. 대표 장식은 HTML과 CSS만으로 구현한다.

## 검증 기준

- 홈페이지 소스에서 활동 기록 대표 영역이 게임 카드 그리드보다 먼저 나온다.
- `AI 바이브 코딩 참가자들의 활동 기록 살펴보기` 문구가 홈페이지 첫 화면과 기억의 조각 시작 화면에 표시된다.
- 대표 버튼은 `games/memory_fragments/index.html`로 연결된다.
- 홈페이지에서 기억의 조각 링크는 대표 버튼 한 곳에만 존재한다.
- 일반 게임 목록에는 기존 12개 게임이 유지된다.
- 데스크톱과 모바일에서 대표 영역이 가로 화면을 넘지 않는다.
- 기억의 조각 시작, 네 구역 이동, 엔딩 기능은 변경 후에도 정상 작동한다.
- 메인 페이지와 기억의 조각 관련 공개 파일이 HTTP 200을 반환한다.
