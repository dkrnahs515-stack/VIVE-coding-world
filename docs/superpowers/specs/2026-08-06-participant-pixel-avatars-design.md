# 참가자 픽셀 아바타 적용 디자인

## 목표

`기억의 조각`에 등록된 네 참가자를 닉네임의 인상과 활동 내용에 맞는 128×128 픽셀 상반신 초상형 아바타로 표현한다. 작은 카드에서도 각 참가자를 쉽게 구분할 수 있게 하고, 개별 참가자의 게임으로 이동하는 기능은 제거해 활동 회고 탐색에 집중한다.

## 아바타 콘셉트

| 닉네임 | 시각 콘셉트 | 대표 색상 |
| --- | --- | --- |
| 닠네임💀 | 해골 가면과 탐정 코트를 착용한 미스터리 탐정 | 핑크·다크 네이비 |
| 멜론빵맨🍈🍞 | 멜론빵 모양 헬멧을 쓴 밝은 탐정·게임 제작자 | 멜론 그린·골드 |
| 냉동병아리🦟 | 얼음 갑옷을 입은 작은 병아리 검사 | 아이스 블루·옐로 |
| 미니미니메추리🐧 | 펭귄 후드와 미래형 헤드셋을 착용한 게임 제작자 | 인디고·시안 |

네 이미지는 동일한 픽셀 밀도, 상반신 구도, 정면 또는 약한 3/4 시점, 균일한 여백을 사용한다. 글자·로고·워터마크는 넣지 않는다.

## 파일과 데이터

- 최종 이미지는 `games/memory_fragments/assets/avatars/`에 PNG로 저장한다.
- 파일명은 영문 소문자와 하이픈을 사용한다.
- 참가자 데이터에는 `avatar` 상대 경로를 추가한다.
- `gameUrl` 필드와 관련 정규화·화면 제어 코드는 제거한다.
- 이미지 로딩에 실패하면 기존 참가자 이모지를 대체 표시해 화면이 깨지지 않게 한다.

## 화면 적용

### 기억 조각 카드

- 현재 큰 이모지 영역을 72×72 아바타 썸네일로 교체한다.
- 픽셀 이미지는 `image-rendering: pixelated`로 표시한다.
- 참가자 색상을 테두리와 은은한 글로우에 사용한다.
- 닉네임, 제작 게임 제목, 읽기 상태는 현재 구조를 유지한다.

### 상세 대화상자

- 기존 62×62 이모지 박스를 80×80 아바타로 교체한다.
- 닉네임과 게임 제목은 아바타 오른쪽에 유지한다.
- `이 참가자의 게임 보기` 링크는 HTML과 JavaScript에서 완전히 제거한다.

### 엔딩 메시지

- 참가자별 마지막 한마디 왼쪽에 48×48 아바타를 표시한다.
- 모바일에서는 아바타와 닉네임이 한 줄에서 자연스럽게 줄어들도록 구성한다.

## 접근성·반응형

- 아바타는 닉네임 옆의 장식 이미지이므로 빈 `alt`를 사용해 중복 낭독을 막는다.
- 카드 버튼의 기존 `aria-label`은 유지한다.
- 580px 이하에서도 아바타가 텍스트 영역을 침범하지 않게 크기를 조정한다.
- 모션 감소 설정에서는 기존 카드 움직임 규칙을 따른다.

## 검증

- 참가자 네 명 모두 안전한 프로젝트 내부 아바타 경로를 가져야 한다.
- 각 아바타 PNG가 128×128이고 브라우저에서 로드되어야 한다.
- 카드, 상세창, 엔딩에 아바타가 표시되어야 한다.
- `gameUrl`, `dialogGameLink`, `이 참가자의 게임 보기`가 코드와 공개 화면에 남아 있지 않아야 한다.
- 기존 네 구역, 16개 기억 조각, 엔딩 및 메인 복귀 흐름이 유지되어야 한다.
