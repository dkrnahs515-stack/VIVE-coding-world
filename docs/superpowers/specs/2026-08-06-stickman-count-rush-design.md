# STICKMAN COUNT RUSH 디자인

## 1. 목표

`STICKMAN COUNT RUSH`는 밝은 색상의 심플한 스틱맨 군단을 좌우로 움직여 관문을 선택하고, 적 군단을 돌파하며 최고 기록에 도전하는 무한 진행형 2.5D 웹게임이다.

게임은 VIVE Coding World의 새 게임 카드에서 진입하며 GitHub Pages에서 별도 설치 없이 실행한다. 기존 게임의 고유 이름·그래픽·UI를 복제하지 않고, 군단 증식과 자동 전진이라는 장르의 핵심 재미만 참고해 독자적인 화면과 규칙을 사용한다.

## 2. 확정된 방향

- 통합 위치: VIVE Coding World 메인 아케이드
- 화면 방식: HTML Canvas 기반 2.5D 원근 표현
- 진행 방식: 끝없이 달리며 최대 인원과 점수를 겨루는 무한 기록 도전
- 핵심 비중: 관문 선택과 군단 전투의 균형
- 조작: 마우스·터치 드래그 전용
- 테마: 밝은 색상의 심플한 스틱맨 군단
- 외부 게임 엔진과 빌드 과정 없음

## 3. 핵심 플레이 규칙

### 3.1 시작과 이동

- 플레이어는 파란색 스틱맨 5명으로 시작한다.
- 군단은 자동으로 전진한다.
- 플레이어는 화면을 누른 상태에서 좌우로 드래그해 군단의 가로 위치를 조절한다.
- 입력을 놓아도 자동 전진은 계속된다.

### 3.2 관문

도로에는 좌우 선택형 관문 두 개가 한 세트로 등장한다.

- 유리한 파란 관문: `+10`, `+20`, `×2`
- 불리한 빨간 관문: `−15`, `−30`, `÷2`
- 나누기 결과는 소수점을 버린 정수로 처리한다.
- 감산 결과는 0보다 작아질 수 없으며, 결과가 0이면 즉시 게임 오버가 된다.
- 지나치게 불리한 조합만 연속해서 등장하지 않도록 생성 규칙에 보정값을 둔다.
- 관문 세트는 약 80~120m 간격으로 배치한다.

### 3.3 군단 전투

- 관문 2~3세트마다 빨간색 적 군단이 등장한다.
- 적과 충돌하면 자동 전투 상태로 전환한다.
- 전투 중 양쪽 인원이 일정한 간격으로 1명씩 감소한다.
- 적이 먼저 0명이 되면 남은 아군으로 자동 달리기를 재개한다.
- 아군이 0명이 되면 게임이 종료된다.

### 3.4 거대 스틱맨

- 500m마다 노란색 거대 스틱맨 보너스 전투가 등장한다.
- 승리하면 아군 25명과 250점 보너스를 받는다.
- 거대 스틱맨의 체력은 이동 거리와 현재 난이도에 비례해 증가한다.

### 3.5 장애물

- 회색 회전봉과 이동 블록이 도로 일부를 가로막는다.
- 장애물과 충돌하면 현재 인원의 10%를 올림한 수만큼 잃되, 최소 1명을 잃는다.
- 한 번 충돌한 뒤 0.5초 동안은 같은 장애물의 추가 피해를 받지 않는다.
- 좁아지는 도로에서는 군단 중심의 이동 범위만 줄어들며, 도로 밖으로 즉시 추락하는 규칙은 사용하지 않는다.

### 3.6 난이도와 기록

이동 거리에 따라 다음 요소가 단계적으로 상승한다.

- 자동 전진 속도
- 적 군단 규모
- 위험 관문 출현 비율
- 움직이는 장애물의 빈도
- 도로가 좁아지는 구간의 빈도

난이도 단계는 250m마다 1씩 오른다. 점수는 이동 거리 1m당 1점, 처치한 적 1명당 10점, 유리한 관문으로 늘어난 인원 1명당 2점, 거대 스틱맨 승리 보너스 250점을 합산한다. 최고 점수, 최대 인원, 최장 거리는 브라우저에 저장한다.

실제 인원은 최대 9,999명까지 계산한다. 9,999명을 넘는 증가는 초과 인원만큼 점수 보너스로 변환한다. 화면에는 성능을 위해 최대 약 120명의 대표 스틱맨만 렌더링한다.

## 4. 화면과 UI

### 4.1 시각 방향

- 스마트폰 세로 화면을 중심으로 설계하고 PC에서는 게임 화면을 중앙에 표시한다.
- 밝은 하늘, 구름, 파스텔색 건물과 원근감 있는 회색 도로를 사용한다.
- 아군은 파란색, 적군은 빨간색, 보너스 캐릭터는 노란색으로 구분한다.
- 스틱맨은 머리, 몸통, 팔, 다리를 Canvas 도형으로 그린다.
- 화면 안쪽에 있을수록 작고, 플레이어 쪽으로 가까워질수록 크게 그려 2.5D 원근감을 만든다.
- 달리기 팔다리 움직임, 충돌 흔들림, 인원 증감 팝업을 제공한다.

### 4.2 시작 화면

- 제목: `STICKMAN COUNT RUSH`
- 설명: `좋은 관문을 선택해 군단을 키우고 적을 돌파하세요.`
- 조작 안내: `화면을 누른 채 좌우로 드래그`
- `게임 시작` 버튼
- `메인 아케이드로 나가기` 버튼

### 4.3 플레이 HUD

- 상단 왼쪽: 현재 인원
- 상단 중앙: 이동 거리
- 상단 오른쪽: 현재 점수
- 일시정지 버튼
- 첫 플레이에서만 드래그 안내 손가락 애니메이션

### 4.4 결과 화면

- 최종 점수
- 최장 거리
- 최대 인원
- 최고 기록
- `다시 도전` 버튼
- `메인으로 나가기` 버튼

### 4.5 메인 아케이드 카드

- 아이콘: `👥`
- 제목: `STICKMAN COUNT RUSH`
- 설명: `좋은 관문을 선택해 군단을 늘리고 끝없이 몰려오는 적을 돌파하세요.`
- 링크: `games/stickman_count_rush/`

## 5. 기술 구조

```text
games/stickman_count_rush/
├─ index.html
├─ style.css
├─ game-core.js
├─ renderer.js
├─ input.js
└─ game.js
```

### 5.1 파일 책임

- `index.html`: 시작 화면, HUD, Canvas, 일시정지·종료 화면의 마크업
- `style.css`: 세로형 반응형 레이아웃과 DOM 오버레이 스타일
- `game-core.js`: 관문 연산, 점수, 난이도, 전투와 생성 규칙
- `renderer.js`: 도로, 배경, 스틱맨, 관문, 장애물의 Canvas 렌더링
- `input.js`: Pointer Events 기반 마우스·터치 드래그 처리
- `game.js`: 게임 상태, 게임 루프, 각 모듈 연결과 DOM 갱신

각 파일은 전역 `StickmanRush` 네임스페이스 아래에 필요한 기능만 공개한다. 빌드 도구나 ES 모듈 서버 설정 없이 GitHub Pages에서 바로 동작하도록 일반 스크립트 파일을 순서대로 불러온다.

### 5.2 상태와 데이터 흐름

게임 상태는 `ready`, `playing`, `paused`, `battle`, `gameover`로 구분한다.

1. `input.js`가 드래그 위치를 정규화한 가로 값으로 전달한다.
2. `game.js`가 현재 상태와 시간 간격을 기준으로 월드 데이터를 갱신한다.
3. `game-core.js`가 관문, 전투, 점수와 난이도의 순수 계산을 수행한다.
4. `renderer.js`가 갱신된 월드 상태를 Canvas에 그린다.
5. `game.js`가 인원·거리·점수 DOM을 갱신한다.

렌더링은 `requestAnimationFrame`을 사용하고, 이동과 전투 계산에는 프레임 간 시간 차이를 사용한다. 프레임이 크게 지연되면 최대 시간 간격을 제한해 캐릭터가 한 번에 관문이나 적을 통과하지 않게 한다.

## 6. 안정성과 오류 대응

- 장치 화소 비율은 최대 2로 제한하고 화면 크기 및 방향 변경 시 Canvas를 다시 맞춘다.
- 게임 영역에서 드래그할 때 브라우저 스크롤과 확대 동작을 막는다.
- `pointerup`, `pointercancel`, 창 포커스 해제를 모두 처리해 입력이 고정되지 않게 한다.
- 문서가 숨겨지거나 창 포커스를 잃으면 자동으로 일시정지한다.
- `localStorage` 읽기·쓰기는 `try/catch`로 감싸 저장이 차단돼도 게임을 계속할 수 있게 한다.
- 장시간 플레이 중 생성 객체가 쌓이지 않도록 화면 밖 객체를 제거하고 재사용 가능한 배열을 쓴다.
- 관문, 적, 장애물 생성기는 최소 회피 공간과 생존 가능한 경로를 보장한다.

## 7. 테스트와 완료 기준

### 7.1 자동 테스트

- `+10`, `+20`, `×2`, `−15`, `−30`, `÷2` 결과
- 0명 이하 방지와 게임 오버 판정
- 9,999명 상한과 초과 점수 변환
- 전투 후 남은 인원 계산
- 거리별 난이도와 점수 계산
- 생성 보정 규칙이 불리한 조합을 연속 생성하지 않는지 확인

### 7.2 브라우저 테스트

- PC 마우스 드래그와 모바일 터치 드래그
- 드래그 중 페이지 스크롤 방지
- 세로·가로 화면 회전과 반응형 Canvas
- 자동 일시정지와 재개
- 다시 시작 및 메인 이동
- 장시간 무한 진행
- 대표 스틱맨 약 120명 렌더링 시 프레임 유지

### 7.3 저장소 통합 완료 기준

- `games/stickman_count_rush/`에서 게임이 실행된다.
- 루트 `index.html`에 새 게임 카드가 표시되고 링크가 정상 동작한다.
- `README.md`의 게임 목록과 파일 구조가 갱신된다.
- 기존 테스트와 새 게임 테스트가 모두 통과한다.
- GitHub Pages의 PC·모바일 화면에서 시작, 플레이, 종료, 재시작, 메인 복귀가 확인된다.

## 8. 제외 범위

첫 버전에는 다음 기능을 넣지 않는다.

- 온라인 순위표와 로그인
- 캐릭터 스킨 상점
- 배경음악과 외부 음원 파일
- 실제 3D 모델과 WebGL 엔진
- 키보드 전용 조작
- 스테이지 선택 화면

이 기능들은 기본 무한 달리기 루프와 모바일 조작이 안정화된 뒤 확장할 수 있다.
